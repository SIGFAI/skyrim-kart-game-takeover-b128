# Kart Game Takeover

**Skyrim** × Kart Game · visual · idea by the team

Bring Kart Game into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned Riverwood into a kart circuit with a finish gate, boost pads and a thunder bolt item; Antler Andy's elk drives a wrecked kart.

## Install

Copy Sigf.esp plus the Scripts, Meshes and Textures folders into Skyrim Special Edition's Data folder and enable Sigf.esp. Load a game near Riverwood: the kart race starts by itself a few seconds later.
